# 🌏 環境小偵探｜全班即時搶答

這是「水域／陸域」課堂活動的手機搶答版。

## 使用方式

1. 老師開啟網站，選「老師開房」。
2. 把 6 位數房間碼投影給學生。
3. 學生用手機開同一個網址，選「學生加入」。
4. 學生輸入房間碼與暱稱。
5. 老師按「開始搶答」。
6. 每題 10 秒；答對依剩餘時間取得分數。
7. 老師畫面會顯示即時排行榜。

## 題目

依原教材的 9 個環境分類題：
高山、森林、草地、潮間帶、海洋、溪流、湖泊、水田、生態池。

## 技術

純前端 GitHub Pages + PeerJS 即時連線。學生手機直接與老師瀏覽器建立資料連線，不需要另外建立資料庫帳號。

注意：老師的瀏覽器分頁需要保持開啟；如果老師關閉分頁，房間就會停止。
